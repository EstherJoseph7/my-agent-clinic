# AgentClinic

A minimal React + Vite experience shell for the AgentClinic product.

## Local setup

```bash
npm install
```

## Useful commands

```bash
npm run dev
npm run build
npm test
npm run validate
```

- `npm run dev`: serves the app locally in development mode.
- `npm run build`: runs strict TypeScript validation and creates the production bundle.
- `npm test`: runs the focused Vitest smoke test for the home page.
- `npm run validate`: runs the production build and Vitest suite together.

This phase keeps the interface informational, accessible, and responsive without introducing product workflows or persistence.
